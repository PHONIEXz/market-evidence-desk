05 / HOW IT WORKS

A small evidence system with a clear chain of custody.

The project connects published sources, research questions, evidence claims, human review, and an AI agent that must show its work.

Open the research desk ↗Read the sourcebook ↗
01 / RECORD

Sources enter Sanity

Each record keeps a title, URL, publisher, publication date, and source type. That is the receipt layer.

02 / LINK

Claims attach to questions

A claim says what a source supports, conflicts with, or provides as context for a research question.

03 / REVIEW

Uncertainty stays visible

Questions carry a review status. The system does not pretend that model synthesis is an approved conclusion.

04 / ANSWER

The agent reads before writing

The Sanity Context agent queries the dataset and Sourcebook, then returns an evidence-grounded draft with tool receipts.

THE CORE RULE

Every strong sentence needs a traceable receipt.

If the dataset cannot answer a question, the correct output is a clear boundary, not a confident guess.
